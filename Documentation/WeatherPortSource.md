# Weather port source

The weather, cloud integration, visibility and radiation changes were adapted from
[Misfit-Sanctuary/nuclear-14](https://github.com/Misfit-Sanctuary/nuclear-14),
revision `afe1a3627584b45c19a5b1b780e0394ec30d8d8a`.

Runtime names and paths were changed to the local N14 naming convention. This does
not change authorship or licensing. See the upstream repository and its license
notices; the local license files remain unchanged. The imported
`Resources/Audio/_Nuclear14/Weather/sandstorm_loop.ogg` comes from upstream's
`Resources/Audio/_Misfits/N14/Weather/sandstorm_loop.ogg`; renaming it does not
grant a new license for that asset.
